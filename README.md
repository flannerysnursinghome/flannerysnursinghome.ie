# Flannery's Nursing Home — website

The public website for Flannery's Nursing Home, Chapel Road, Abbeyknockmoy, Tuam, Co. Galway.

Published with GitHub Pages from the `main` branch, so anything committed here goes live within a
minute or two.

## How it is built

The pages are generated from a single build script kept separately; they are plain HTML here and can
be edited directly if needed. Styles are in `assets/css/site.css`, photographs in `assets/img`,
typefaces in `assets/fonts` (self-hosted, no third-party requests).
